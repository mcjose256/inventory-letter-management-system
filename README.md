# Digital Inventory & Letter Management System

## Overview
A web-based system designed to digitize inventory requests and official letter tracking within a faculty or institutional environment.  
The system replaces manual record-keeping with real-time tracking, approvals, and reporting.

---

## Modules
### Inventory Management
- Item request submission
- Approval workflow
- Real-time request status tracking
- Stock visibility for admins and storekeepers
- Usage and stock reports

### Letter Management
- Digital logging of incoming and outgoing letters
- Delivery status tracking
- Search and filtering
- Summary reports (no file attachments)

---

## User Roles
- **Admin** – Full system access and approvals
- **Faculty Staff** – Submit and track item requests
- **Storekeeper** – Manage stock and update request status
- **Office Attendant** – Log and track letters

---


---

## Purpose
- Improve accountability and transparency
- Reduce delays in inventory and letter handling
- Enable data-driven decision-making
